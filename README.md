# 平台总体架构规划

## 目标概述
- 构建一个面向“基础模型管理”全流程的平台，覆盖模型管理、预训练模塑创建、源数据提取、模型训练、模型发布五大能力域。
- 采用前后端分离的方式，提供统一的 API 网关对外暴露接口，满足业务扩展性、可观测性与安全要求。

## 架构总览
平台整体划分为三层：
1. **体验层（前端）**：提供模型、数据、训练任务、服务发布等管理界面。
2. **服务层（后端应用）**：封装各核心域服务，负责业务流程与权限控制。
3. **基础设施层**：数据库、对象存储、向量数据库、消息队列、容器编排、监控告警等。

## 前端设计
- **技术栈**：React/Vue + TypeScript，结合组件库（Ant Design/Element Plus）快速构建界面。
- **模块划分**：
  - 模型目录管理：模型分组、版本列表、服务实例状态。
  - 模塑模板创建：可视化拖拽配置、参数表单、模板发布流程。
  - 源数据接入：数据源管理、数据抽取任务、质量校验结果展示。
  - 训练任务编排：任务拓扑、资源占用监控、训练日志实时查看。
  - 模型发布：灰度发布、服务流量监控、回滚控制。
- **状态管理**：采用 React Query/Pinia 处理异步数据流，统一封装 API SDK。
- **鉴权与多租户**：前端基于 JWT/OIDC 获取访问令牌，界面层控制菜单与操作权限。
- **可视化与联动**：利用 WebSocket/SSE 实时更新训练状态、数据同步进度。

## 后端设计
- **网关与鉴权**：
  - API 网关负责路由、限流、熔断和审计，统一处理 OIDC/SAML 登录流程。
  - 租户与角色权限服务提供 RBAC/ABAC 能力，支持精细化操作控制。
- **领域服务拆分**：
  1. **应用模型管理服务**：维护模型元数据、版本信息、依赖关系，提供生命周期管理 API。
  2. **预训练模塑创建服务**：管理模板库、参数配置、模板审批流程。
  3. **源数据接取服务**：适配多种数据源（数据库、对象存储、数据湖），支持批/流同步，提供数据质量报告。
  4. **模型训练流水线服务**：结合工作流编排（Airflow/KubeFlow），调度训练任务、资源分配、结果存储。
  5. **模型发布与运营服务**：接入服务网格，实现灰度、蓝绿发布，监控服务健康。
  6. **评测与反馈服务**（可选）：执行离线/在线评测，采集反馈闭环。
- **数据层**：
  - 关系型数据库保存业务元数据与流程状态。
  - 向量数据库/知识库存储向量化后的模型与数据索引。
  - 对象存储保存训练产物、数据文件。
- **事件驱动**：通过 Kafka/Redis Stream 解耦跨域事件，如训练完成通知、数据抽取状态、发布事件。
- **任务编排**：Airflow/KubeFlow 负责任务 DAG 管理；Celery/Argo Events 处理短时异步任务。
- **服务治理**：容器化部署至 Kubernetes，借助 Istio/Linkerd 提供服务发现、熔断、指标。

## 数据与模型治理
- 建立数据血缘、质量、标签体系，配合元数据服务形成数据资产视图。
- 模型版本化管理：利用 Model Registry（MLflow/自研）记录模型签名、评测结果。
- 制定合规与审计流程，记录关键操作日志，满足监管要求。

## DevOps 与运维
- **CI/CD**：采用 GitLab CI/GitHub Actions 构建镜像，自动化测试与部署。
- **环境管理**：
  - 多环境（Dev/QA/Prod）隔离，配置中心分环境管理。
  - IaC（Terraform/Helm）定义基础资源。
- **可观测**：Prometheus 收集指标，Loki/ELK 聚合日志，Grafana 可视化；接入告警中心。
- **安全**：
  - 密钥与证书统一存储在 Vault/KMS。
  - 服务间通信启用 mTLS。
  - 数据加密、访问审计、合规校验。

## 实施路径建议
1. **原型阶段**：完成核心模型管理、数据接入、训练编排基础功能，搭建前后端骨架与 API 网关。
2. **扩展阶段**：加入模板审批、模型发布、评测反馈等能力，完善监控告警。
3. **运营阶段**：优化用户体验、自动化运营（如训练成本分析、资源弹性伸缩），持续迭代模型治理与安全策略。
